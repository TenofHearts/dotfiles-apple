OmniWM shortcuts

Left Option + H / J / K / L focuses windows across displays; Left Option + 1–9 switches workspaces. Left Option + M minimizes; Left Option + Q closes. All work in every mode while management is active.

Left Option means the modifier received after Karabiner remapping; your left physical Command key currently sends Left Option. Release modifiers after entering a mode before pressing plain keys.

Left Option + Escape always resets to Main, including with Shift held.

Move

Activate: Left Option + Shift + ; → M

KeyAction
H / J / K / LNative Dwindle move: join a touching tile or extract the active tab; cross monitors at an edge. This changes group membership.
Shift + H / J / K / LSwap the active workspace with the adjacent display’s active workspace (both displays change).
1–9Move to workspace and follow the window; stay in Move.

Dwindle groups use tabs. Joining two existing groups requires extracting the active tab, then joining it. Arbitrary AeroSpace container trees cannot be reproduced.

Escape or Enter → Main. Left Option + Shift + ; → Command.

Adjust

Activate: Left Option + Shift + ; → R

KeyAction
H / LShrink / grow width: native 10% split step in Dwindle, 25 points in Niri.
J / KGrow / shrink height: native 10% split step in Dwindle, 25 points in Niri.
TSet tiled. Use F again to exit fullscreen.
WToggle floating / tiling; stay in Adjust.
FToggle fullscreen without outer margins.
SpaceCycle this workspace’s layouts: Dwindle → Niri → Dwindle; stay in Adjust.
MMinimize.

Escape or Enter → Main. Left Option + Shift + ; → Command.

Admin

Activate: Left Option + Shift + ; → A

KeyAction
RReload skhd bindings; exit Admin. OmniWM settings reload automatically when saved.
PReturn to Main and quit OmniWM, leaving window management stopped.

Resume by launching OmniWM or running scripts/wm-service.sh start. There is no stable CLI command for pausing management.

Escape or Enter → Main. Left Option + Shift + ; → Command.

Effects & gestures

Keyboard shortcuts below start in Main. Option is received after Karabiner remapping.

InputAction
Option + `Toggle the sliding glass Quake terminal.
Three fingers ↑ / ↓Swipe between workspaces with animated settling.
Three fingers ← / →Momentum-scroll Niri columns (when using Niri).
Option + drag / right-dragSwap tiled windows / resize.

Overview is disabled because its search bar overlaps the camera notch. Niri scrolling and workspace swipe animations remain enabled. Captured swipe previews need OmniWM Screen Recording permission. Gradient focus borders, subtle glow, app icons in tab rails, and tiling animations are enabled. Keyboard workspace selection remains immediate in OmniWM 0.7.6.

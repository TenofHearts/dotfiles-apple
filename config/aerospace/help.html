AeroSpace shortcuts

Option + H / J / K / L focuses windows; Option + 1–9 switches workspaces. Option + M minimizes; Option + Q closes. All work in every mode while management is active.

Option means the modifier received after Karabiner remapping; your left physical Command key currently sends Option. Release modifiers after entering a mode before pressing plain keys.

MainCommandMoveAdjustAdmin

Main

Active by default

KeyAction
Option + H / J / K / LFocus left / down / up / right.
Option + 1–9Switch workspace.
Option + Shift + ;Enter Command.

Command

Activate: Option + Shift + ;

KeyAction
MEnter Move.
REnter Adjust.
AEnter Admin.
HOpen this guide in the default browser; exit Command.

Escape, Enter or Option + Shift + ; → Main.

Move

Activate: Option + Shift + ; → M

KeyAction
H / J / K / LMove left / down / up / right.
Shift + H / J / K / LMove the whole workspace to the display left / down / up / right.
VToggle horizontal / vertical tiles.
1–9Move to workspace and follow the window; stay in Move.

Escape or Enter → Main. Option + Shift + ; → Command.

Adjust

Activate: Option + Shift + ; → R

KeyAction
H / LShrink / grow width by 25 points.
J / KGrow / shrink height by 25 points.
TSet tiled.
FToggle fullscreen.
SpaceToggle floating / tiling.
MMinimize.

Escape or Enter → Main. Option + Shift + ; → Command.

Admin

Activate: Option + Shift + ; → A

KeyAction
RReload configuration; exit Admin.
PReturn to Main and pause window management.

Resume management manually from the AeroSpace menu-bar icon or CLI.

Escape or Enter → Main. Option + Shift + ; → Command.

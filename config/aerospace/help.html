AeroSpace hotkeys

`Alt` means the Option modifier received after Karabiner remapping. Your left physical Command key currently sends Option. Release modifiers after entering a mode before pressing plain keys.

| Context | Keys | Action |
| --- | --- | --- |
| Every mode | Option+H/J/K/L | Focus left/down/up/right |
| Every mode | Option+M / Option+Q | Minimize / close window |
| Every mode | Option+1–9 | Focus workspace 1–9 |
| Main | Option+Shift+; | Enter command mode |
| Command | H | Open local hotkey help, return to main |
| Command | M / R / A | Enter move / adjust / admin |
| Command | Option+Shift+; | Return to main |
| Move | H/J/K/L | Move left/down/up/right |
| Move | V | Toggle horizontal/vertical tiles |
| Move | 1–9 | Move window to workspace and follow it |
| Adjust | H / L | Shrink / grow width by 25 points |
| Adjust | J / K | Grow / shrink height by 25 points |
| Adjust | T / F / Space / M | Tile / fullscreen / toggle floating / minimize |
| Admin | P | Return to main and pause; resume manually |
| Admin | R | Return to main and reload AeroSpace |
| Move, adjust, admin | Option+Shift+; | Return to command |
| Any non-main mode | Escape / Enter | Return to main |

AeroSpace modes replace the previous mode; common Option shortcuts are explicitly repeated in each mode.
